# api-hello-node 🚀

Minha primeira API REST desenvolvida com Node.js e Express. Projeto em evolução constante.

**Objetivo**: Consolidar conhecimentos em Backend para conquistar primeira vaga como Desenvolvedor Jr PcD.

### **🛠️ Stack**
- Node.js
- Express.js
- JavaScript

### **📍 Endpoints**
| Método | Rota | Descrição |
| --- | --- | --- |
| GET | `/` | Retorna mensagem de boas-vindas e status |
| GET | `/health` | Verifica saúde da API |

### **▶️ Como rodar localmente**
1. Clone o repo: `git clone https://github.com/vinicius-wanderley/api-hello-node`
2. Instale as dependências: `npm install express`
3. Rode o servidor: `node index.js`
4. Acesse: `http://localhost:3000`
